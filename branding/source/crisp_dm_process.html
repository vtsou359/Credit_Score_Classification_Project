CRISP-DM, as applied in this project
Six phases, run iteratively: evaluation findings send the work back to earlier phases.
iterate: customer-level re-validation after the leakage check
1

Business understanding

Financial inclusion: can ML predict a customer’s credit tier (Poor / Standard / Good)?

2

Data understanding

100K monthly records, 28 columns: corrupted values, outliers, missing data.

3

Data preparation

Customer-level cleaning and imputation, feature selection, scaling and encoding pipelines.

4

Modelling

6 model families tuned with GridSearchCV and k-fold cross-validation on ROC-AUC.

5

Evaluation

ROC-AUC, confusion matrices, overfitting checks and a data-leakage check.

6

Deployment

Recommendation: Gradient Boosting for accuracy, Logistic Regression for speed.

DataKaggle “Credit Score Classification” · 100,000 records · 12,500 customers × 8 months · target: Poor / Standard / Good
